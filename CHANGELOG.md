# Виджет «Шаблоны задач» для amoCRM — сводка проекта

Разработчик: **ИП Кононенко Елена Витальевна (KO:AGENCY)** ·
поддержка: https://t.me/ko_agency, koagency.me@gmail.com
Ветка разработки: `claude/peaceful-sagan-pbntox` · текущая версия: **1.1.4**

Аналог виджета [«Шаблоны задач» YouPlatform](https://youplatform.ru/widgets/shabloni-zadach).

## Что делает
Постановка задач в один клик по заранее настроенным шаблонам из карточки
сделки/контакта/компании, из окна выбора, из раздела Задачи и из переключателя
типа сообщения. Шаблон задаёт: комментарий, тип задачи (в т.ч. кастомные типы
аккаунта), срок (пресеты или ручная дата), ответственного.

## Ключевые возможности
- Блок в карточке с фирменной красной плашкой KO:AGENCY (через caption-класс).
- Модальные окна: выбор шаблона, редактор, форма создания.
- Хранение шаблонов в служебном списке amoCRM (переживает перезагрузку,
  общее для аккаунта); данные не покидают аккаунт.
- Постановка задач через `POST /api/v4/tasks`; ответственный «за карточку»
  резолвится через API.
- Кастомные типы задач (`AMOCRM.constant('task_types')` + account, merge).
- Локализация ru/en. Автотесты — 179 проверок (`node test/run-tests.js`).

## Структура
- `widget/` — виджет: `manifest.json`, `script.js`, `i18n/`, `images/`.
- `test/run-tests.js` — локальный стенд (jsdom + jQuery + эмуляция amoCRM API).
- `scripts/make_logos.py` — генератор логотипов.
- `docs/` — комплект публикации (см. ниже).
- `qa-reports/` — данные ручного тестирования.

## Комплект публикации в amoМаркет (`docs/`)
- `amomarket-publish.md` — чек-лист готовности и шаги сабмита.
- `amomarket.md` — тексты листинга (ru/en).
- `privacy-policy.md` — политика конфиденциальности (реквизиты ИП).
- `offer.md` — публичная оферта (тариф 490 ₽/аккаунт/мес + триал 14 дней).
- `moderator-note.md` — пояснение для модератора.
- `instruction.md` — инструкция для пользователей.
- `test-plan.md` — чек-лист ручного тестирования.

## Монетизация
Платный: **490 ₽/аккаунт в месяц + пробный период 14 дней**. Оплата — через
биллинг amoМаркета (код оплаты в виджете не нужен).

## Флаг нативных входов
Пункты в переключателе типа сообщения и в меню раздела Задачи — включены
(`NATIVE_UI_DEFAULT = true`). Это зона риска модерации; при замечании
переключаются в moderation-safe режим флагом `yp_native_ui: false`
(остаётся официальное ядро). Покрыто тестом.
