# QA: данные тестирования

Сюда загружайте всё, что относится к **ручному тестированию** виджета
«Шаблоны задач» на боевом аккаунте https://koagency.amocrm.ru/, чтобы я видел
полную картину и понимал контекст:

- отчёты о прогоне (по чек-листу `docs/test-plan.md`);
- скриншоты интерфейса и консоли (F12 → Console);
- вывод диагностических строк (например `YP build=… menus=… item=…`);
- HTML-фрагменты из инспектора (когда нужно увидеть реальную вёрстку);
- заметки «что не работает» в свободной форме.

## Как удобнее называть файлы

Чтобы я быстро ориентировался — по дате и теме, например:

```
qa-reports/2026-06-13_otchet-progona.md
qa-reports/2026-06-13_pereklyuchatel-console.txt
qa-reports/2026-06-13_screenshot-card.png
```

Формат любой (`.md`, `.txt`, `.png`, `.html`, `.json`) — главное, чтобы было
понятно, к какому кейсу относится. Если кладёте скриншот — можно рядом
короткий `.md` с подписью, что на нём и где это в интерфейсе.

## Где что лежит в проекте (для связи)

- `docs/test-plan.md` — чек-лист тест-кейсов (по нему удобно отмечать ✅/❌/⏭️).
- `docs/instruction.md` — инструкция для пользователя.
- `test/run-tests.js` — автотесты (локальный стенд, `node test/run-tests.js`).
- `widget/` — сам виджет (`script.js`, `manifest.json`, `i18n/`, `images/`).

## Текущая метка сборки

Версия виджета видна в браузере: `#yp-tt-styles` → атрибут `data-v`
(на момент создания папки — `2026-06-13.3`). Указывайте её в отчётах — так я
точно знаю, какая сборка тестировалась.
