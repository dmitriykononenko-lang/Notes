# Тексты для amoМаркета

## Название

Шаблоны задач

## Короткое описание (до ~100 символов)

Постановка задач в один клик по готовым шаблонам из карточки сделки, контакта или компании.

## Полное описание

Виджет «Шаблоны задач» избавляет менеджеров от рутины при постановке однотипных задач.

Один раз настройте шаблоны — и ставьте задачи в один клик:

- **Шаблон задаёт всё**: комментарий, тип задачи (звонок, встреча и любые типы вашего
  аккаунта), срок выполнения и ответственного.
- **Гибкие сроки**: в момент создания, через 15/30 минут, через час, до конца дня,
  завтра, через 2–3 дня, через неделю — или выбор даты вручную при постановке.
- **Ответственный**: текущий пользователь, ответственный за карточку или конкретный
  сотрудник.
- **Удобный выбор**: в окне выбора видно, какая задача получится — срок, ответственный,
  тип и комментарий — ещё до постановки.
- **Простой редактор**: создание, изменение и удаление шаблонов без программиста —
  прямо из карточки или из настроек виджета.

Работает в карточках сделок, контактов и компаний. Не требует стороннего сервера —
данные хранятся в вашем amoCRM.

## Сценарии использования

- «Перезвонить клиенту» — звонок текущему менеджеру через час.
- «Получить оплату» — задача ответственному за сделку через 2 дня до конца дня.
- «Встреча с клиентом» — встреча с выбором даты вручную.
