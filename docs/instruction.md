# Инструкция: установка и использование виджета «Шаблоны задач»

Аккаунт: https://koagency.amocrm.ru/

## Установка (один раз, нужны права администратора)

1. Соберите архив виджета (или возьмите готовый `task-templates.zip`):

   ```bash
   cd widget && zip -r ../task-templates.zip . && cd ..
   ```

2. В amoCRM откройте **amoМаркет** (левое меню) → справа вверху **Разработчикам**
   → **Создать интеграцию** → **Приватная интеграция**.
3. На вкладке интеграции отметьте, что интеграция содержит **виджет**, и загрузите
   `task-templates.zip`. Заполните название и описание (можно взять из
   `docs/amomarket.md`).
4. Сохраните и **установите** интеграцию в аккаунт.
5. При установке откроются настройки виджета — добавьте первые шаблоны кнопкой
   **«+ новый шаблон»** и нажмите **Сохранить**.

## Как поставить задачу по шаблону

1. Откройте карточку сделки, контакта или компании.
2. В правой колонке найдите блок **«Шаблоны задач»** и нажмите
   **«Поставить задачу по шаблону»**.
3. В окне «Выберите шаблон для постановки задачи» кликните по нужному шаблону.
   На карточке шаблона видно, какой получится задача: «До {дата} для {ответственный}»
   и «{тип} — {комментарий}».
4. Если у шаблона включён «Выбор даты вручную», укажите дату и время и нажмите
   **«Поставить задачу»**.
5. Появится уведомление «Задача создана» — задача видна в карточке и в разделе Задачи.

## Как редактировать шаблоны

- **Из карточки**: ссылка «Редактор шаблонов» под кнопкой, либо такая же ссылка
  в окне выбора шаблона. Сохранение из карточки идёт через API и требует прав
  администратора аккаунта.
- **Через настройки** (работает всегда): amoМаркет → Установленные →
  «Шаблоны задач» → Настройки. Изменения сохраняет стандартная кнопка **Сохранить**.

В редакторе: клик по названию шаблона — редактирование, корзина — удаление,
«+ новый шаблон» — создание.

## Поля шаблона

| Поле | Описание |
|------|----------|
| Название шаблона | Отображается в списке выбора |
| Со сроком выполнения | Пресет: в момент создания, через 15/30 минут, через час, до конца дня, завтра, через 2/3 дня, через неделю |
| Выбор даты вручную | Дата и время запрашиваются при постановке задачи |
| Ответственный | Текущий пользователь, ответственный за карточку или конкретный сотрудник |
| Тип задачи | Звонок, встреча и другие типы, настроенные в аккаунте |
| Комментарий | Текст задачи; если пуст, используется название шаблона |

## Если что-то не работает

- Блок не появился в карточке — обновите страницу (Ctrl+F5), проверьте, что
  интеграция установлена и виджет включён.
- «Не удалось сохранить шаблоны» в редакторе из карточки — у пользователя нет
  прав администратора; отредактируйте шаблоны через настройки виджета.
- «Не удалось создать задачу» — проверьте права пользователя на создание задач
  и откройте консоль браузера (F12 → Console), чтобы увидеть ответ API; пришлите
  скриншот разработчику.
