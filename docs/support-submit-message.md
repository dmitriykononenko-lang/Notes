## Описание работы виджета
Виджет «Шаблоны задач» позволяет заранее настроить шаблоны задач и ставить
задачи в один клик. Шаблон задаёт: комментарий, тип задачи (включая
пользовательские типы аккаунта), срок выполнения (пресеты или выбор даты
вручную) и ответственного (текущий пользователь, ответственный за карточку или
конкретный сотрудник). Задачи создаются штатным методом API `POST /api/v4/tasks`.
Виджет обращается только к API того же аккаунта amoCRM, внешних серверов не
использует; данные шаблонов хранятся в служебном списке аккаунта.

## Как подключить и как работать
Установка (один раз, права администратора):
1. Установить интеграцию «Шаблоны задач».
2. При установке откроются настройки виджета → добавить шаблоны кнопкой
   «+ новый шаблон»: указать название, тип задачи, срок (пресет или «выбор
   даты вручную»), ответственного, комментарий → «Сохранить».

Постановка задачи (ежедневное использование):
1. Открыть карточку сделки/контакта/компании.
2. В правой колонке в блоке «Шаблоны задач» нажать «Поставить задачу по
   шаблону» (либо выбрать «Шаблоны задач» в переключателе типа сообщения внизу
   карточки).
3. В окне выбора кликнуть по шаблону — задача создаётся автоматически с
   комментарием, типом, сроком и ответственным из шаблона. Если у шаблона
   включён «выбор даты вручную» — указать дату и нажать «Поставить задачу».

Редактирование шаблонов:
- Из карточки: ссылка «Редактор шаблонов» под кнопкой или в окне выбора.
- Из раздела Задачи: меню «…» → «Редактор шаблонов».
- Через настройки виджета.
В редакторе: клик по названию — правка, корзина — удаление, «+ новый шаблон» —
создание.
