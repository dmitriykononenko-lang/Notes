## Описание работы виджета
Виджет «Шаблоны задач» позволяет заранее настроить шаблоны задач и ставить
задачи в один клик. Шаблон задаёт: комментарий, тип задачи (включая
пользовательские типы аккаунта), срок выполнения (пресеты или выбор даты
вручную) и ответственного (текущий пользователь, ответственный за карточку или
конкретный сотрудник). Задачи создаются штатным методом API `POST /api/v4/tasks`.
Виджет обращается только к API того же аккаунта amoCRM, внешних серверов не
использует; данные шаблонов хранятся в служебном списке аккаунта.

## Как подключить и как работать
1. Установить интеграцию, при установке в настройках добавить шаблоны
   («+ новый шаблон» → указать название, тип, срок, ответственного, комментарий).
2. Открыть карточку сделки/контакта/компании → в блоке «Шаблоны задач»
   (правая панель) нажать «Поставить задачу по шаблону» → выбрать шаблон →
   задача создаётся автоматически.
3. Также шаблон можно выбрать из переключателя типа сообщения внизу карточки,
   а редактор шаблонов открыть из карточки, из окна выбора или из настроек.
Полная инструкция: [ССЫЛКА НА ИНСТРУКЦИЮ — при желании выложить docs/instruction.md].
