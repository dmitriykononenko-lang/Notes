дословно. Значения в `[скобках]` уточни у владельца, если не сможешь найти сам.

## Шаг 1. Открыть интеграцию
amoCRM → **Настройки → Интеграции** → открыть интеграцию **«Шаблоны задач»**
→ «Редактировать».

## Шаг 2. Загрузить архив и заполнить поля
- **Архив с пользовательским кодом** → «Загрузить» → выбрать `task-templates.zip`
  (версия 1.1.5).
- **Логотип 400×272** — оставить красный KO:AGENCY (уже загружен).
- **Ссылка для перенаправления:** `https://koagency.amocrm.ru/`.
- **Ссылка для хука об отключении** — оставить пустой.
- **Предоставить доступ: Все** — включить (галочка).
- **Контроль дублей / Множественные источники** — выключены.

## Шаг 3. Найти ID интеграции
В карточке интеграции → вкладка **«Ключи и доступы»** → скопировать
**ID интеграции** (длинная строка). Секретный ключ и код авторизации НЕ
передавать никому.

## Шаг 4. Отправить на модерацию
Открыть **чат техподдержки** в аккаунте amoCRM и отправить сообщение
(вставить дословно, подставив ID интеграции и телефон):

---
Здравствуйте! Просим опубликовать виджет в amoМаркете.

Аккаунт: koagency.amocrm.ru
Интеграция: «Шаблоны задач», ID интеграции: [ID ИНТЕГРАЦИИ]
Разработчик: ИП Кононенко Елена Витальевна (KO:AGENCY)
Модель: платный, 490 ₽/аккаунт в месяц, пробный период 14 дней.
Контакты поддержки: тел. [ТЕЛЕФОН], e-mail koagency.me@gmail.com, Telegram https://t.me/ko_agency.
Языки публикации: русский, английский.

Описание работы: виджет «Шаблоны задач» позволяет заранее настроить шаблоны и
ставить задачи в один клик. Шаблон задаёт комментарий, тип задачи (в т.ч.
пользовательские типы аккаунта), срок (пресеты или выбор даты вручную) и
ответственного. Задачи создаются штатным методом POST /api/v4/tasks. Виджет
обращается только к API того же аккаунта, внешних серверов не использует; данные
шаблонов хранятся в служебном списке аккаунта.

Как подключить и работать:
1) Установить интеграцию; при установке в настройках добавить шаблоны
   («+ новый шаблон»: название, тип, срок, ответственный, комментарий).
2) В карточке сделки/контакта/компании нажать «Поставить задачу по шаблону»
   (или выбрать «Шаблоны задач» в переключателе внизу карточки) → выбрать
   шаблон → задача создаётся автоматически. При «выборе даты вручную» указать
   дату.
3) Редактор шаблонов: из карточки, из окна выбора, из меню «…» раздела Задачи
   или из настроек виджета.

Тестовые данные не требуются: виджет работает только внутри аккаунта amoCRM,
подключений к сторонним системам нет. Достаточно установить виджет и создать
1–2 шаблона.

Примечание: виджет создаёт служебный список «Шаблоны задач (данные виджета)»
для хранения настроек; данные не покидают аккаунт, удалять список не нужно.

С уважением, KO:AGENCY (ИП Кононенко Е.В.).

## Шаг 5. Отработать замечания модерации
Если модератор укажет на встраивание в нативный интерфейс amoCRM (пункт в
переключателе типа сообщения и в меню раздела Задачи) — сообщи владельцу:
доступна **moderation-safe сборка** (флаг `yp_native_ui: false`), где эти
входы отключены, а всё ядро (блок в карточке, окно выбора, редактор, настройки,
постановка задач) работает. Тогда собрать новую версию, поднять номер версии в
manifest.json и залить заново (Шаг 2), затем ответить модератору.
