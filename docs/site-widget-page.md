# Шаблоны задач для amoCRM

**Постановка задач в один клик по готовым шаблонам — прямо из карточки сделки,
контакта или компании.**

Менеджеры тратят время на однотипные задачи: «перезвонить», «получить оплату»,
«назначить встречу». Виджет «Шаблоны задач» убирает эту рутину — настройте
шаблоны один раз и ставьте задачи в один клик, с уже готовыми сроком, типом и
ответственным.

## Что умеет

- **Шаблон задаёт всё сразу:** комментарий, тип задачи (звонок, встреча и любые
  ваши типы), срок выполнения и ответственного.
- **Гибкие сроки:** в момент создания, через 15/30 минут, через час, до конца
  дня, завтра, через 2–3 дня, через неделю — или выбор даты вручную.
- **Ответственный:** текущий пользователь, ответственный за карточку или
  конкретный сотрудник.
- **Понятный выбор:** перед постановкой видно, какой получится задача — срок,
  ответственный, тип и комментарий.
- **Удобные точки входа:** блок в карточке, переключатель типа сообщения,
  раздел «Задачи».
- **Простой редактор:** создание, изменение и удаление шаблонов без
  программиста.

## Как это работает

1. Установите виджет и добавьте шаблоны в настройках.
2. В карточке сделки/контакта/компании нажмите **«Поставить задачу по шаблону»**.
3. Выберите шаблон — задача создаётся автоматически с нужными параметрами.

Готово: вместо ручного заполнения полей — один клик.

## Частые вопросы

**Где хранятся данные?** Внутри вашего аккаунта amoCRM. Виджет не использует
сторонних серверов и не передаёт данные третьим лицам.

**Нужен ли программист?** Нет. Шаблоны настраиваются в понятном редакторе.

**Поддерживаются кастомные типы задач?** Да — виджет подхватывает все типы
задач вашего аккаунта.

**Языки интерфейса:** русский и английский.
