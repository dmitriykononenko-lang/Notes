# Пояснение для модератора amoМаркета

Виджет «Шаблоны задач» (ИП Кононенко Елена Витальевна, KO:AGENCY).

## Что делает виджет
Позволяет заранее настроить шаблоны задач (комментарий, тип, срок, ответственный)
и ставить задачи в один клик из карточки сделки/контакта/компании, из раздела
Задачи и из переключателя типа сообщения. Задачи создаются штатным методом
`POST /api/v4/tasks`.

## Данные и приватность
- Виджет обращается **только к API того же аккаунта** amoCRM (same-origin,
  `/api/v4/...`). Внешних запросов к сторонним доменам нет.
- Собственного бэкенда нет. Данные шаблонов **не покидают аккаунт** клиента.
- Не используются cookie и аналитика. Нет `eval`, нет внешних скриптов.

## Почему виджет создаёт список «Шаблоны задач (данные виджета)»
Для хранения настроек шаблонов виджет создаёт служебный список (catalog) через
`/api/v4/catalogs` и хранит в нём один элемент с JSON шаблонов. Это нужно, чтобы
шаблоны сохранялись между сессиями и были общими для пользователей аккаунта.
Список служебный, содержит только техническую запись; пользовательские данные
в сторонние системы не передаются. Удаление списка очищает шаблоны.

## Используемые области (locations)
Карточки сделки/контакта/компании (`lcard-1`, `ccard-1`, `comcard-1`),
`everywhere` (пункт в разделе Задачи и в переключателе типа сообщения),
`settings` (редактор шаблонов в настройках).
