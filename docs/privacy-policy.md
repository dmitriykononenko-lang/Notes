## 1. Общие положения

Настоящая политика описывает, какие данные обрабатывает виджет «Шаблоны задач»
(далее — Виджет) при использовании в аккаунте amoCRM.

## 2. Какие данные обрабатываются

Виджет работает внутри интерфейса amoCRM и обращается только к API того же
аккаунта amoCRM (same-origin). Виджет обрабатывает:

- настройки шаблонов задач (название, текст/комментарий, тип задачи, срок,
  ответственный), которые задаёт пользователь;
- идентификаторы открытой карточки (сделки/контакта/компании) и пользователя —
  только для постановки задачи через штатный API amoCRM;
- справочные данные аккаунта (типы задач, список сотрудников) — для отображения
  в интерфейсе виджета.

## 3. Где хранятся данные

Шаблоны хранятся **внутри вашего аккаунта amoCRM** — в служебном списке
«Шаблоны задач (данные виджета)». Виджет **не передаёт данные на сторонние
серверы** и не использует внешних сервисов: собственного бэкенда у Виджета нет.

## 4. Передача третьим лицам

Виджет не передаёт персональные и иные данные третьим лицам. Все операции
выполняются в рамках вашего аккаунта amoCRM средствами его официального API.

## 5. Cookie и аналитика

Виджет не устанавливает собственные cookie и не использует системы аналитики.

## 6. Права пользователя

Вы в любой момент можете изменить или удалить шаблоны через «Редактор шаблонов»,
а также удалить Виджет (интеграцию) из аккаунта. При удалении служебного списка
«Шаблоны задач (данные виджета)» сохранённые шаблоны удаляются.
