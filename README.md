# Шаблоны задач — виджет для amoCRM

Виджет для постановки задач в один клик по заранее настроенным шаблонам.
Функциональный аналог виджета [«Шаблоны задач» YouPlatform](https://youplatform.ru/widgets/shabloni-zadach).

## Возможности

- **Шаблоны задач** с параметрами:
  - название шаблона;
  - комментарий (текст задачи);
  - тип задачи (звонок, встреча и пользовательские типы аккаунта);
  - срок выполнения — пресеты «в момент создания», «через 15/30 минут», «через час»,
    «до конца дня», «завтра», «через 2/3 дня», «через неделю»;
  - опция «Выбор даты вручную» — дата запрашивается в момент постановки задачи;
  - ответственный — текущий пользователь, ответственный за карточку или конкретный сотрудник.
- **Постановка задачи в один клик**: кнопка в правой колонке карточки сделки, контакта
  или компании открывает модальное окно «Выберите шаблон для постановки задачи» с
  карточками шаблонов — вычисленный срок («До 11.01.2025 13:04 для Viktor Borisenko»),
  тип и комментарий. Клик по карточке создаёт задачу через API amoCRM (`POST /api/v4/tasks`).
- **Редактор шаблонов** — модальное окно со списком шаблонов (клик по названию —
  редактирование, корзина — удаление) и кнопкой «+ новый шаблон». Открывается из
  карточки и из окна выбора шаблона; тот же редактор встроен в настройки виджета.
- **Локализация**: русский и английский.
- **Без бэкенда**: шаблоны хранятся в настройках виджета (JSON в поле `templates`),
  отдельный сервер не нужен. Сохранение из редактора в карточке идёт через
  `POST /api/v4/widgets/{code}` (нужны права администратора); резервный путь —
  редактирование в настройках виджета.

## Структура проекта

```
widget/
├── manifest.json   # описание виджета: локации, настройки, версия
├── script.js       # логика: рендер в карточках, редактор, создание задач
└── i18n/
    ├── ru.json     # русская локализация
    └── en.json     # английская локализация
```

## Сборка и установка

1. Соберите архив виджета (файлы должны лежать в корне архива):

   ```bash
   cd widget && zip -r ../task-templates.zip . && cd ..
   ```

2. В amoCRM откройте **amoМаркет → Разработчикам → Создать интеграцию**
   (приватная интеграция), на вкладке виджета загрузите `task-templates.zip`.
3. Установите интеграцию в аккаунт. При установке откроются настройки виджета —
   добавьте шаблоны в редакторе и нажмите «Сохранить».

## Использование

1. Откройте карточку сделки, контакта или компании.
2. В правой колонке в блоке **«Шаблоны задач»** нажмите **«Поставить задачу по шаблону»**.
3. В модальном окне кликните по нужному шаблону — задача будет создана с комментарием,
   типом, сроком и ответственным из шаблона. Если в шаблоне включён «Выбор даты вручную»,
   виджет сначала спросит дату и время. Об успехе сообщит всплывающее уведомление.

Редактирование шаблонов: ссылка **«Редактор шаблонов»** в карточке или в окне выбора
шаблона (требуются права администратора для сохранения через API), либо
**amoМаркет → Установленные → Шаблоны задач → Настройки**.

## Формат хранения шаблонов

Шаблоны сохраняются в поле настроек `templates` как JSON-массив:

```json
[
  {
    "id": "tpl_1749700000000_1234",
    "name": "Перезвонить клиенту",
    "text": "Перезвонить клиенту и уточнить решение по предложению",
    "task_type_id": 1,
    "deadline": "tomorrow",
    "manualDate": false,
    "responsible": "current"
  }
]
```

- `task_type_id` — id типа задачи аккаунта (1 — звонок, 2 — встреча);
- `deadline` — пресет срока: `now` | `min15` | `min30` | `hour1` | `today_end` |
  `tomorrow` | `days2` | `days3` | `week`;
- `manualDate` — если `true`, дата и время запрашиваются при постановке задачи;
- `responsible` — `"current"` (текущий пользователь), `"entity"` (ответственный
  за карточку) или числовой id сотрудника.

## Ограничения и идеи развития

- Шаблоны общие для всего аккаунта (хранятся в настройках виджета); права на
  отдельные шаблоны по отделам — возможное развитие.
- У YouPlatform заявлены также предустановленные варианты закрытия задач и запуск
  Salesbot по результату выполнения — эти функции требуют серверной части и могут
  быть добавлены следующим этапом.
