# Шаблоны задач — виджет для amoCRM

Виджет для постановки задач в один клик по заранее настроенным шаблонам.
Функциональный аналог виджета [«Шаблоны задач» YouPlatform](https://youplatform.ru/widgets/shabloni-zadach).

## Возможности

- **Шаблоны задач** с параметрами:
  - название шаблона;
  - текст задачи;
  - тип задачи (звонок, встреча и пользовательские типы аккаунта);
  - срок выполнения — через N минут / часов / дней, опционально с переносом на конец дня;
  - ответственный — текущий пользователь, ответственный за карточку или конкретный сотрудник.
- **Постановка задачи в один клик** из карточки сделки, контакта или компании: виджет
  отображается в правой колонке карточки, клик по шаблону сразу создаёт задачу
  через API amoCRM (`POST /api/v4/tasks`).
- **Редактор шаблонов** в настройках виджета: добавление, редактирование и удаление
  шаблонов без правки JSON вручную.
- **Локализация**: русский и английский.
- **Без бэкенда**: шаблоны хранятся в настройках виджета (JSON в поле `templates`),
  отдельный сервер не нужен.

## Структура проекта

```
widget/
├── manifest.json   # описание виджета: локации, настройки, версия
├── script.js       # логика: рендер в карточках, редактор, создание задач
└── i18n/
    ├── ru.json     # русская локализация
    └── en.json     # английская локализация
```

## Сборка и установка

1. Соберите архив виджета (файлы должны лежать в корне архива):

   ```bash
   cd widget && zip -r ../task-templates.zip . && cd ..
   ```

2. В amoCRM откройте **amoМаркет → Разработчикам → Создать интеграцию**
   (приватная интеграция), на вкладке виджета загрузите `task-templates.zip`.
3. Установите интеграцию в аккаунт. При установке откроются настройки виджета —
   добавьте шаблоны в редакторе и нажмите «Сохранить».

## Использование

1. Откройте карточку сделки, контакта или компании.
2. В правой колонке найдите блок **«Шаблоны задач»**.
3. Кликните по нужному шаблону — задача будет создана с текстом, типом, сроком
   и ответственным из шаблона. Об успехе сообщит всплывающее уведомление.

Редактирование шаблонов: **amoМаркет → Установленные → Шаблоны задач → Настройки**.

## Формат хранения шаблонов

Шаблоны сохраняются в поле настроек `templates` как JSON-массив:

```json
[
  {
    "id": "tpl_1749700000000_1234",
    "name": "Перезвонить клиенту",
    "text": "Перезвонить клиенту и уточнить решение по предложению",
    "task_type_id": 1,
    "deadline": { "amount": 1, "unit": "days", "endOfDay": true },
    "responsible": "current"
  }
]
```

- `task_type_id` — id типа задачи аккаунта (1 — звонок, 2 — встреча);
- `deadline.unit` — `minutes` | `hours` | `days`; `amount: 0` означает «сразу»;
- `responsible` — `"current"` (текущий пользователь), `"entity"` (ответственный
  за карточку) или числовой id сотрудника.

## Ограничения и идеи развития

- Шаблоны общие для всего аккаунта (хранятся в настройках виджета); права на
  отдельные шаблоны по отделам — возможное развитие.
- У YouPlatform заявлены также предустановленные варианты закрытия задач и запуск
  Salesbot по результату выполнения — эти функции требуют серверной части и могут
  быть добавлены следующим этапом.
